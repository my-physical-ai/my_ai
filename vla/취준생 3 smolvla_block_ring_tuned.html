SmolVLA 학습 명령어
태스크 성격별 파라미터 튜닝

두 태스크의 난이도가 다릅니다. 작고 형태가 다양한 블록은 정밀 대응(4090·5090, 강한 튜닝), 크고 형태가 일정한 링은 표준 구성(3070·4070)으로 나눴습니다. 파라미터는 SmolVLA 논문·실전 파인튜닝 사례를 분석해 태스크별로 다르게 잡았습니다.

🔍 두 태스크의 성격 차이

파라미터를 다르게 잡은 이유입니다. 물체 특성이 학습 난이도와 필요 자원을 결정합니다.

🧱 블록 팀 — 어려움 (정밀)

  • 블록이 작다 → grasp 지점을 정밀하게 맞춰야 함
  • 크기·형태가 다양 → 여러 형태에 일반화 필요
  • 작은 물체 = 위치 오차에 민감 → 데이터 밀도·steps↑
  • 강한 이미지 증강으로 형태 다양성 대응

💍 링 팀 — 상대적으로 쉬움 (표준)

  • 링이 크다 → grasp 여유가 큼
  • 형태가 일정(원형 고리) → 크기만 다양
  • 큰 고리 삽입은 clearance 여유 → 빠르게 수렴
  • 표준 steps·증강 최소로 충분
🌐 파라미터 근거 (글로벌 분석): SmolVLA 논문은 작은 lego brick을 넣는 태스크가 "특히 정밀한 grasp를 요구"한다고 명시합니다. 정밀 태스크 벤치마크에서는 SmolVLA를 batch 16 · 50,000 steps로 학습했고, 실전 SO-101 큐브 파인튜닝 사례는 작은 큐브의 정밀 grasp에는 데이터 밀도가 중요하다고 보고합니다. 반면 링(고리) 삽입은 clearance가 큰 ring-insertion이 좁은 peg-insertion보다 빠르게 수렴한다는 결과가 있어, 링 팀은 표준 30,000 steps로 구성했습니다. 공통 기반값(AdamW lr 5e-5 · cosine)은 SmolVLA 파인튜닝 표준 설정을 따릅니다.
🎛️ 실행 전 공통 3가지:
① REPO_ID · DATASET_ROOT · OUTPUT_DIR를 자기 데이터로 수정
② pip install -e ".[smolvla]" --break-system-packages 설치 확인
③ 카메라 키 확인 — 웹캠 3대(top/side/wrist) 기준. 카메라 구성이 다르면 rename_map 수정
🚨 색상 구분 태스크 필수: --policy.freeze_vision_encoder=false — 빨강/파랑/녹색을 구분해야 하므로 vision encoder를 반드시 풀어야 합니다. 두 팀 모두 동일하게 적용됩니다.

🧱 블록 팀 — 작은 블록을 통에 넣기 (정밀)

작고 형태가 다양한 블록을 정밀하게 집어 보라색 통(purple bin)에 넣습니다. 4090·5090으로 50,000 steps·강한 증강·grad_clip 1.0으로 정밀도를 끌어올립니다.

📝 블록 팀 태스크 문구 (--dataset.single_task):
🔴 빨강"Put the red block into the purple bin"
🔵 파랑"Put the blue block into the purple bin"
🟢 녹색"Put the green block into the purple bin"
🎯 블록 팀 튜닝 포인트 (표준 대비 변경): steps 50,000(↑, 정밀·다양성) · image_transforms=true(강한 증강) · grad_clip_norm=1.0(다양한 형태 안정화) · warmup 2,000 / decay 48,000 · chunk_size=50(정밀 grasp).
🧱
블록 팀 · 정밀batch 16 · 50,000 steps · aug ON · grad_clip 1.0
🟠 4090 24GB 
# ── 블록 팀 · 정밀 │ RTX 4090 (24GB) ──
# 작은/다양한 블록 → 정밀 grasp: steps↑, 강한 증강, grad_clip 1.0
# 수정 필요: REPO_ID, DATASET_ROOT, OUTPUT_DIR
PYTORCH_ALLOC_CONF=expandable_segments:True \
lerobot-train \
  --policy.path=lerobot/smolvla_base \
  --dataset.repo_id="${REPO_ID}" \
  --dataset.root="${DATASET_ROOT}" \
  --output_dir="${OUTPUT_DIR}" \
  --rename_map='{"observation.images.top":"observation.images.camera1","observation.images.side":"observation.images.camera2","observation.images.wrist":"observation.images.camera3"}' \
  --job_name=smolvla_block_4090 \
  --policy.device=cuda \
  --policy.use_amp=false \
  --batch_size=16 \
  --steps=50000 \
  --save_freq=5000 \
  --log_freq=100 \
  --policy.freeze_vision_encoder=false \
  --policy.chunk_size=50 \
  --policy.n_action_steps=50 \
  --dataset.image_transforms.enable=true \
  --optimizer.type=adamw \
  --optimizer.lr=5e-5 \
  --optimizer.weight_decay=1e-4 \
  --optimizer.grad_clip_norm=1.0 \
  --scheduler.type=cosine_decay_with_warmup \
  --scheduler.num_warmup_steps=2000 \
  --scheduler.num_decay_steps=48000 \
  --scheduler.peak_lr=5e-5 \
  --scheduler.decay_lr=1e-6 \
  --policy.push_to_hub=false \
  --wandb.enable=false

💍 링 팀 — 큰 링을 링봉에 끼우기 (표준)

크고 형태가 일정한 링(크기만 다양)을 집어 링봉(peg)에 끼웁니다. 형태가 일정해 상대적으로 쉬우므로 3070·4070으로 표준 30,000 steps·증강 OFF로 학습합니다.

📝 링 팀 태스크 문구 (--dataset.single_task):
🔴 빨강"Pick the red ring and place it on the peg"
🔵 파랑"Pick the blue ring and place it on the peg"
🟢 녹색"Pick the green ring and place it on the peg"
🎯 링 팀 튜닝 포인트 (표준 유지): steps 30,000(형태 일정 → 빠른 수렴) · image_transforms=false(형태 일정, 과증강 불필요) · grad_clip_norm=0.5 · warmup 1,000 / decay 29,000. 크기 다양성은 실제 여러 크기의 링을 골고루 수집해 확보합니다.

⚙️ 학습 완료 후 필수 작업 (두 팀 공통)

SmolVLA는 학습 후 n_action_steps를 확인·수정해야 추론이 부드럽습니다. 블록 팀은 학습 명령에 이미 n_action_steps=50을 넣었지만, 저장된 config가 1로 남아 있으면 아래로 보정하세요.

🔧 n_action_steps 확인/수정 (1 → 50)모든 체크포인트에 적용
# 학습 완료 후 — 모든 체크포인트의 config.json 확인/수정
find "${OUTPUT_DIR}" -name "config.json" -path "*/pretrained_model/*" \
  -exec sed -i 's/"n_action_steps": 1/"n_action_steps": 50/' {} \;

# 확인
grep "n_action_steps" "${OUTPUT_DIR}/checkpoints/last/pretrained_model/config.json"
