🗼 무작위 탑쌓기
2개 → 3개 → (덤)4개

책상에 아무렇게나 흩어진 블록을 로봇이 찾아서 차곡차곡 탑으로! 쉬운 단계부터 배워 어려운 단계로 확장하는 커리큘럼 학습의 정석이에요.

무작위 초기 배치 커리큘럼 학습 누적 오차 warm start
① 무엇을 하나 ② 왜 무작위? ③ 왜 단계별? ④ 데이터 횟수 ⑤ 색깔 선택 ⑥ 실습 명령어 ⑦ 취업 포인트

① 무엇을 하는 실습인가?

한 문장으로: 무작위로 놓인 블록을 로봇이 집어서 안 무너지게 탑으로 쌓기.

🟠 2층 : 중상 🔴 3층 : 어려움 🎯 2층 ~70~96% / 3층 ~30~50% 📸 단계별 200회
🧱
이해하기 쉽게!

블록쌓기 놀이를 생각해봐요. 블록이 바닥에 아무 데나 흩어져 있으면, 하나씩 집어서 정확히 위에 올려 탑을 만들죠. 조금만 삐뚤어도 무너져요. 로봇에게 이걸 시키는 거예요 — 그것도 매번 위치가 바뀌는 상황에서!

💡 실제로는 — 로봇이 카메라로 블록을 보고(Vision), "쌓아라"는 명령을 이해(Language)하고, 팔을 움직여(Action) 탑을 만들어요. 이게 VLA(Vision-Language-Action)의 전형적인 작업이에요.

🎬 전체 흐름: 무작위로 흩어진 블록 → 로봇이 찾아서 → 중심 맞춰 차곡차곡 탑으로

② 왜 "무작위로" 놓아야 할까?

항상 같은 자리에 놓으면 안 돼요. 무작위가 진짜 실력을 키웁니다.

🎯
이해하기 쉽게!

구구단을 항상 "2×3"만 외우면 "2×7"은 못 풀죠? 여러 문제를 풀어봐야 진짜 이해예요. 로봇도 블록이 항상 같은 자리면 위치를 통째로 외워버려요. 무작위로 놔야 로봇이 "블록이 어디 있든 보고 판단"하는 걸 배워요.

💡 실제로는 — 실제 SO-101 스택 연구도 매 에피소드 블록 위치를 무작위로 놨어요. 무작위 배치가 로봇 학습의 표준입니다.

🎲 고정 위치는 "암기"라 응용 불가 / 무작위는 "이해"라 어디서든 성공
📚
검증된 사실: 데이터 모을 때 블록을 여러 위치(최소 5곳)에 놓고, 각 위치마다 반복 녹화하면 로봇이 훨씬 잘 일반화해요. "변형마다 반복"이 핵심 원칙입니다.

③ 왜 2개 → 3개 → 4개 "단계별"로?

처음부터 4층에 도전하면 실패해요. 쉬운 것부터 배워 확장하는 게 커리큘럼 학습이에요.

🪜
이해하기 쉽게!

수영을 배울 때 물에 뜨기 → 발차기 → 자유형 순서로 배우죠? 갑자기 자유형부터 하면 물 먹어요. 로봇도 2층부터 → 3층 → 4층으로 올려야 각 단계에서 배운 걸 다음 단계에 써먹어요.

💡 실제로는 — 2층 쌓기를 배운 모델을 출발점(warm start)으로 3층을 배우면, "블록 집기·올리기" 기본기가 이미 있어서 훨씬 빨리 배워요.

🪜 2층(기초) → warm start → 3층 → warm start → 4층(덤). 층 올릴수록 어려워짐
1단계 · 기본
🧱 2개 탑
200회

블록 집기+올리기 기초. 성공률 70%+ 목표. 여기가 토대!

2단계 · 확장
🏗️ 3개 탑
200회

2층 모델 warm start. 누적오차(1mm가 쌓임) 관리 학습.

덤 · 도전
🗼 4개 탑
200회

3층 모델 warm start. 재시도 로직 필수. "왜 무너지나" 분석이 핵심.

🔴
솔직한 진실 (누적 오차): 층이 올라갈수록 성공률이 급격히 떨어져요. 배치할 때 1mm 오차가 위층으로 갈수록 쌓여 결국 무너지거든요. ACT 사례에서 2층 96% → 4층 78%로 떨어졌어요. 이걸 이해하고 관리하는 게 실력이에요.

④ 데이터 몇 번? 어떻게 학습?

여러분 경험대로 단계마다 200회가 좋아요. 그리고 학습 방식이 중요해요.

📸
왜 200회? SmolVLA는 변형마다 충분히 반복해야 안정적이에요. 25회는 부족(성능 나쁨), 50회는 최소선, 200회면 넉넉합니다. 작업 범위를 10cm로 좁게 시작하면 적은 데이터로도 성공률이 높아요.

🔑 학습 방식 : 순차 warm start (7번은 이게 정답!)

✅
7번은 순차 warm start가 잘 통해요. 왜냐면 2층이 3층에 "포함"되거든요. 3층을 배워도 2층 능력을 까먹지 않아요. 여러분이 경험한 "1단계 200회 → 2단계 200회"가 잘 되는 대표 케이스예요!
학습 방식어떻게7번에서는?
순차 warm start
⭐추천		2층 모델을 출발점으로 3층 학습, 3층을 출발점으로 4층✅ 딱 맞음. 포함관계라 안 까먹음. 데이터·시간 절약
통합 재학습2·3·4층 데이터를 모두 합쳐 처음부터△ 가능하나 7번엔 과함. 시간·비용만 더 듦
맨땅부터4층을 처음부터 바로 학습❌ 비효율. 기초 없이 어려운 것부터 = 실패 위험
⚠️
꼭 확인! 3층 학습 후 2층도 다시 테스트하세요. 만약 2층 성공률이 떨어졌으면 (드물지만) 그때는 통합 재학습으로 전환. "포함관계라 안전"하지만 검증은 필수예요.

⑤ 블록 색깔은 어떻게 고를까?

색깔도 성공률에 영향을 줘요. 층마다 다른 원색이 정답이에요.

🎨
이해하기 쉽게!

비슷한 색(주황·연두)은 카메라가 헷갈려요. 사람도 비슷한 색은 구분 어렵죠? 빨강·파랑·초록 같은 원색은 뚜렷이 달라서 로봇이 "이건 몇 번째 블록"인지 쉽게 알아봐요.

💡 실제로는 — 층마다 색을 다르게 하면, 영상에서 어느 층이 어긋났는지 한눈에 보여요. 디버깅과 발표 영상에 큰 도움이 돼요.

🎨 빨강·파랑·초록 원색은 카메라가 잘 구분 / 주황·노랑 계열은 헷갈림
🎨
추천 색 조합: 1층 🔵파랑 · 2층 🔴빨강 · 3층 🟢초록 · 4층 🟡노랑. 배경은 무채색(흰색·회색), 조명은 링라이트 백색광이면 대비 최고예요.

⑥ 실습 명령어 (녹화 → 학습 → 추론)

실제로 돌리는 순서예요. 2층부터 시작해 warm start로 올려요.

1️⃣ 녹화 : 무작위 위치로 200회

# 2층 데이터 녹화 (블록 위치를 매번 바꿔가며 200회)
lerobot-record \
  --robot.type=so101_follower --robot.port=/dev/ttyACM0 \
  --robot.cameras="{ top: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30},     wrist: {type: intelrealsense, serial_number_or_name: XXXX, width: 640, height: 480, fps: 30} }" \
  --dataset.repo_id=$HF_USER/tower_2 \
  --dataset.single_task="Stack the blocks into a tower" \
  --dataset.num_episodes=200 \
  --teleop.type=so101_leader --teleop.port=/dev/ttyACM1
💡
single_task는 이 작업의 명령이에요. 녹화·학습·추론에서 똑같은 텍스트를 쓰세요. 3층 데이터는 repo_id=$HF_USER/tower_3로 따로 녹화하면 돼요.

2️⃣ 학습 : 2층 먼저 → 3층은 warm start

# ① 2층 학습 (베이스 모델에서 시작)
lerobot-train --policy.path=lerobot/smolvla_base \
  --dataset.repo_id=$HF_USER/tower_2 \
  --batch_size=64 --steps=20000 \
  --output_dir=outputs/train/tower_2 --policy.device=cuda

# ② 3층 학습 (★ 2층 모델을 출발점으로 = warm start)
lerobot-train --policy.path=outputs/train/tower_2/checkpoint \
  --dataset.repo_id=$HF_USER/tower_3 \
  --batch_size=64 --steps=15000 \
  --output_dir=outputs/train/tower_3 --policy.device=cuda

3️⃣ 추론 : 로봇으로 실행 & 평가

# 학습된 모델로 실제 탑쌓기 실행 (60초)
lerobot-rollout --strategy.type=base \
  --policy.path=outputs/train/tower_3/checkpoint \
  --robot.type=so101_follower --robot.port=/dev/ttyACM0 \
  --task="Stack the blocks into a tower" \
  --duration=60 --device=cuda
1
2층 녹화·학습 — 무작위 200회 → 학습 → 성공률 70%+ 확인.
2
3층 녹화·warm start 학습 — 200회 → 2층 모델 이어서 학습.
3
2층 재테스트 — 3층 학습 후 2층 성공률 안 떨어졌나 확인.
4
(덤) 4층 도전 — 3층 warm start + 재시도 로직. "왜 무너지나" 분석.

⑦ 취업 포인트 & 종합 정리

이 실습으로 무엇을 어필할 수 있는지, 핵심을 정리해요.

📊 7번 한눈 요약표

단계블록데이터학습색깔목표 성공률
1단계2개200회베이스에서파+빨~70~96%

💼 취업 포트폴리오 강점
"무작위 배치 + 2→3→4 커리큘럼 + 층수별 성공률 분석" 조합은 채용 담당자가 가장 좋아하는 데모예요:
① 일반화 능력 (무작위여도 성공) ② 학습 전략 설계 (커리큘럼·warm start 이해) ③ 문제 분석력 ("왜 층이 오르면 실패하나"를 데이터로 설명). 실물 블록이라 비전공 면접관도 이해하는 시연!
🎯
7번의 핵심 3가지: ① 무작위로 놔야 진짜 실력 ② 단계별 warm start로 효율적 확장 (7번은 포함관계라 순차가 정답!) ③ 층마다 원색으로 구분·디버깅 쉽게.
🔗
다음 단계 연결: 탑쌓기를 마스터하면 10번 링 정렬·재스택(스킬 체이닝)이나 롱호라이즌 작업으로 확장할 수 있어요. "여러 작업을 순서대로 잇는" 기술로 나아가는 발판이에요.
💎 핵심 한 줄
무작위에서 시작해 2→3→4층으로 단계별 확장하는 커리큘럼은 실제 연구가 쓰는 정석이에요. 7번은 "탑을 얼마나 높이, 얼마나 안정적으로" 쌓느냐로 로봇 AI의 일반화와 학습 전략을 한 번에 보여주는 최고의 실습입니다!
