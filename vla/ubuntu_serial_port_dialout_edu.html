1포트를 확인하는 5가지 명령어

lerobot-find-port는 "찾기" 명령이고, 목록을 보는 기본 명령은 따로 있습니다.

📬
이해하기 쉽게!

아파트 우편함을 떠올려보세요. ls /dev/ttyACM*는 우편함 전체를 쭉 둘러보는 것이고, lerobot-find-port는 편지를 넣었다 빼면서(USB를 뽑았다 꽂으면서) "내 우편함이 몇 호인지" 정확히 짚어주는 것이에요.

💡 실제로는 — lerobot-find-port는 USB 연결 전/후의 포트 목록 차이를 비교해서 방금 꽂은 장치의 포트를 알려줍니다.

기본 · 가장 많이 사용

① 포트 목록 보기 — ls

연결된 시리얼 포트 장치 파일을 나열합니다. "리스트 명령어"의 정답입니다.

# 시리얼 포트 목록 확인
ls /dev/ttyACM* /dev/ttyUSB* 2>/dev/null
/dev/ttyACM0  /dev/ttyACM1   ← 연결된 포트들
  • ttyACM* → Feetech 모터 보드처럼 USB로 직접 통신하는 장치 (CDC-ACM 방식)
  • ttyUSB* → USB-시리얼 변환칩(FTDI, CH340 등)을 쓰는 장치
  • 2>/dev/null → 장치가 없을 때 나오는 에러 메시지를 숨김
권한 확인

② 자세한 정보 보기 — ls -l

소유자·그룹·권한까지 표시합니다. dialout 그룹이 여기서 등장합니다.

ls -l /dev/ttyACM*
crw-rw---- 1 root dialout 166, 0  7월 25 10:30 /dev/ttyACM0
#            ↑     ↑
#          소유자  그룹 ← 내가 이 그룹에 없으면 접근 불가!
장치 식별

③ USB 장치 전체 보기 — lsusb

포트가 아니라 어떤 USB 장치가 물리적으로 꽂혀 있는지를 보여줍니다.

lsusb
Bus 001 Device 005: ID 1a86:55d3 QinHeng Electronics USB Serial
연결 추적

④ 방금 꽂은 장치의 포트 확인 — dmesg

커널 로그에서 "방금 꽂은 장치가 어느 포트로 잡혔는지" 확인합니다.

sudo dmesg | grep tty
cdc_acm 1-2:1.0: ttyACM0: USB ACM device
듀얼 보드 필수

⑤ 고유 이름으로 보기 — /dev/serial/by-id/

시리얼 번호 기반 이름이라 재부팅·재연결해도 바뀌지 않습니다. 팔/바퀴 듀얼 보드에서 포트가 뒤바뀌는 문제의 해결 열쇠입니다.

ls -l /dev/serial/by-id/
usb-1a86_USB_Serial-if00 -> ../../ttyACM0

# 시리얼 번호로 udev rule 고정 포트 만들기
udevadm info --name=/dev/ttyACM0 | grep SERIAL

2리눅스 철학: "모든 것이 파일"

dialout 권한을 이해하려면 먼저 이 질문에 답해야 합니다 — 왜 USB 포트가 파일로 보일까요?

🗄️
이해하기 쉽게!

리눅스는 모든 하드웨어를 서류함의 서류철처럼 다룹니다. 키보드도, 모니터도, 모터 보드도 전부 /dev/ 폴더 안의 "파일"이라는 서류철 하나로 표현돼요. 서류철에 글을 쓰면 → 장치로 데이터가 나가고, 서류철을 읽으면 → 장치에서 데이터가 들어옵니다.

💡 실제로는 — "Everything is a file"은 UNIX의 핵심 설계 철학입니다. /dev/ttyACM0은 디스크의 일반 파일이 아니라 커널이 만든 캐릭터 장치 파일(character device)이에요. (권한 표시 맨 앞의 c가 그 표시)

이 설계의 결정적 장점: 하드웨어가 파일이 되는 순간, 리눅스의 파일 권한 규칙(소유자/그룹/기타)이 하드웨어에 그대로 적용됩니다. 새로운 보안 체계를 만들 필요 없이, 기존 파일 권한 하나로 모든 장치의 접근을 통제할 수 있죠.

3dialout 그룹은 왜 만들어졌나

이름부터 힌트입니다 — dial-out, "전화를 밖으로 걸다".

🎙️
이해하기 쉽게!

학교 방송실을 떠올려보세요. 방송실 마이크는 아무나 쓰면 안 되죠. 그래서 "방송부원 명단"을 만들고, 명단에 있는 학생만 열쇠를 받습니다. dialout 그룹이 바로 이 방송부원 명단입니다.

💡 실제로는 — sudo usermod -aG dialout $USER = "내 계정을 명단에 올려주세요"

📜 이름의 역사

1970~80년대 · UNIX 시절
시리얼 포트에는 주로 전화 모뎀이 연결되어 있었습니다. 모뎀으로 몰래 국제전화를 걸면 전화비 폭탄 💸 — 그래서 "전화를 걸(dial-out) 수 있는 사람"을 그룹으로 제한했습니다.
1990~2000년대 · 리눅스 보급
모뎀은 사라져 갔지만, 시리얼 포트 권한 관리 체계는 그대로 유지되었습니다. 데비안/우분투 계열이 dialout 그룹을 시리얼 장치의 표준 그룹으로 채택했습니다.
현재 · 로봇/IoT 시대
아두이노, 라즈베리파이, Feetech 모터 보드까지 — USB 시리얼 장치는 전부 dialout 그룹으로 보호됩니다. 이름만 옛날 유산으로 남은 것이죠.

🛡️ 근본 원리: 최소 권한 원칙

어렵게 말하면 최소 권한 원칙(Principle of Least Privilege)이지만, 쉽게 말하면 "꼭 필요한 사람에게만 열쇠를 준다"입니다. 시리얼 포트를 아무나 쓰게 두면:

  • 옛날: 몰래 모뎀으로 국제전화 → 요금 폭탄
  • 지금: 아무 프로그램이나 로봇 모터를 마음대로 제어하거나, 다른 사용자가 쓰는 포트를 가로챌 수 있음

🔬 권한 문자열 해부하기

crw-rw----  root  dialout  /dev/ttyACM0
👑
소유자 root: rw-
읽기 ⭕ 쓰기 ⭕ — 시스템 관리자는 항상 접근 가능
🎫
dialout 그룹: rw-
읽기 ⭕ 쓰기 ⭕ — 명단에 오른 사용자만 통과
🚫
나머지 모두: ---
접근 불가 ❌ — 명단에 없으면 Permission denied
💡
맨 앞의 c는 캐릭터 장치(character device) 표시입니다. 일반 파일은 -, 폴더는 d로 시작해요.

4왜 하필 "그룹" 방식인가

접근을 통제하는 방법은 세 가지가 가능했습니다. 리눅스는 왜 그룹을 택했을까요?

👑

보안높음

🚪

방법 3: 그룹(dialout)

보안필요한 만큼
편의성sudo 불필요
관리명단에 추가만
하면 끝
✅ 보안과 편의의 균형

그룹 방식은 보안(잠가둠)과 편의(sudo 없이 사용)의 중간 해법입니다. 게다가 우분투는 USB 시리얼 장치가 꽂힐 때마다 udev라는 장치 관리자가 자동으로 파일을 dialout 그룹 소유로 만들어주기 때문에, 사용자는 명단에 이름 한 번만 올리면 됩니다.

우분투에는 /usr/lib/udev/rules.d/에 미리 정의된 규칙 파일들이 있습니다. "tty 서브시스템 장치는 dialout 그룹으로" 같은 규칙이 이미 들어있어서, USB를 꽂는 순간 자동 적용됩니다.

LeKiwi 듀얼 보드에서 사용하는 고정 포트 이름 만들기도 같은 원리입니다. /etc/udev/rules.d/99-lekiwi.rules에 시리얼 번호 기반 규칙을 추가하면 /dev/robot_arm, /dev/robot_wheels 같은 이름을 만들 수 있죠: 

SUBSYSTEM=="tty", ATTRS{serial}=="12345ABC", SYMLINK+="robot_arm"
SUBSYSTEM=="tty", ATTRS{serial}=="67890DEF", SYMLINK+="robot_wheels"

5실습: 권한 설정과 재로그인의 비밀

명단에 이름을 올리는 실제 명령과, "왜 재로그인해야 하나요?"에 대한 답입니다.

필수 설정

dialout 그룹에 내 계정 추가하기

# 1. 현재 내 그룹 확인
groups
bigman sudo   ← dialout이 없다!

# 2. dialout 그룹에 추가 (-aG: 기존 그룹 유지하며 추가)
sudo usermod -aG dialout $USER

# 3. ⚠️ 재로그인 또는 재부팅 (필수!)
sudo reboot

# 4. 재접속 후 다시 확인
groups
bigman sudo dialout   ← 성공!
⚠️
-aG에서 -a(append)를 빼먹지 마세요! usermod -G dialout만 쓰면 기존 그룹(sudo 등)이 전부 사라져서 관리자 권한을 잃을 수 있습니다.
🎟️
왜 재로그인이 필요할까?

놀이공원 입장 팔찌를 생각해보세요. 팔찌는 입장할 때 한 번만 채워주죠. 입장 후에 자유이용권을 결제해도, 다시 입장해야 새 팔찌를 받을 수 있습니다. 리눅스도 마찬가지 — 그룹 명단은 로그인하는 순간 한 번만 읽혀서 세션에 도장처럼 찍힙니다.

💡 실제로는 — 로그인 시 프로세스에 그룹 목록이 부여되고, 이미 실행 중인 세션에는 소급 적용되지 않습니다. 그래서 재로그인(또는 재부팅)이 필요해요. (터미널 한 개만 임시로 갱신하려면 newgrp dialout도 가능)
