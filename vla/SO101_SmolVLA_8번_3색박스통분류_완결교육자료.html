♻️ 3색 박스통 분류
색깔 맞춰 통에 넣기

"빨간 블록은 빨간 통에, 파란 블록은 파란 통에" — 분리수거처럼 색을 보고 골라 담기. 언어를 이해해 물체를 구분하는, VLA의 진짜 실력을 시험하는 작업이에요.

색 분류(Sorting) 언어 grounding 통합 재학습 재활용 자동화
① 무엇을 하나 ② 왜 어려운가 ③ 커리큘럼 ④ 학습 방식 ⑤ 색깔·명령 ⑥ 실습 명령어 ⑦ 취업 포인트

① 무엇을 하는 실습인가?

한 문장으로: 블록의 색을 보고, 같은 색 통에 넣기. 분리수거의 로봇 버전이에요.

🔴 난이도 : 상 (색 분류는 어려움!) 🎯 통·대비 잘하면 향상 📸 색깔별 균형 데이터
♻️
이해하기 쉽게!

분리수거를 생각해봐요. 플라스틱은 파란 통, 캔은 초록 통, 종이는 빨간 통에 넣죠? 로봇도 똑같아요 — "빨간 블록은 빨간 통에" 넣게 시켜요. 블록을 집는 것뿐 아니라 색을 보고 어느 통인지 판단까지 해야 해요.

💡 실제로는 — 명령이 "Put the red block in the red bin"처럼 색↔통 짝이에요. 로봇이 색을 인식(Vision) + 명령을 이해(Language) + 올바른 통에 넣기(Action)를 다 해야 해요.

🎬 전체 흐름: "빨강 블록을 빨강 통에" 명령 → 로봇이 색 보고 → 맞는 통에 (분리수거처럼)

② 색 분류는 왜 "어려운" 작업일까?

솔직히 말하면 — 색 분류는 SmolVLA가 가장 어려워하는 작업 중 하나예요. 이유를 알면 대응할 수 있어요.

🔴
솔직한 진실: 연구에서 색 분류(Color Sorting)는 가장 어려운 벤치마크로, 성공률이 0~10%로 매우 낮았어요. SmolVLA는 색을 구분하는 능력이 약한 편이에요(작은 모델이라). 이걸 미리 알고 대비하는 게 실력이에요!
🎨
이해하기 쉽게!

단순히 "블록 집기"는 색을 몰라도 돼요. 하지만 "빨간 것만 골라"는 색을 정확히 알아보고 + 명령과 연결해야 해요. 이건 훨씬 어려운 일이에요. 게다가 SmolVLA는 작고 가벼운 모델이라 색 구분 능력이 큰 모델보다 약해요.

💡 실제로는 — "언어 grounding"(명령의 '빨간'과 실제 빨간 블록을 연결하는 것)이 어려워요. 단순 집기(70~95%)와 달리 색 분류는 성공률이 뚝 떨어져요.

📊 단순 집기(70%)는 쉽지만, 색 분류(5%)는 가장 어려움. 언어 grounding이 필요하기 때문
💡
그래도 방법이 있어요! 성공률을 올리는 3가지 열쇠: ① 통을 명확하게(위치 고정·큰 통) ② 색 대비 최대화(원색+무채색 배경) ③ 통합 재학습(뒤에서 설명). 어렵다고 포기할 게 아니라 제대로 설계하면 돼요.

③ 2색 → 3색 단계별 커리큘럼

처음부터 3색은 어려워요. 2색 2통 먼저 성공시키고 초록을 추가해 확장해요.

🎨
이해하기 쉽게!

색칠 공부할 때 빨강·파랑 두 색부터 익히고 초록을 더하죠? 로봇도 똑같아요. 2색(빨강↔빨강통, 파랑↔파랑통) 먼저 확실히 하고, 잘 되면 초록 통을 추가해 3색으로.

💡 실제로는 — 색이 많아질수록 로봇이 헷갈려요. 2색으로 "색↔통 짝맞춤"의 기본을 다지고 확장하는 게 안전해요.

🎨 2색 2통(빨강·파랑) 먼저 → 초록 추가 → 3색 3통으로 확장
1단계
🔴🔵 2색 2통
색당 100회

빨강↔빨강통, 파랑↔파랑통. 짝맞춤 기본. 총 200회.

2단계
🟢 초록 추가
색당 100회

초록↔초록통 추가. 3색 균형 맞춰 통합 재학습.

⚖️
색깔별 균형이 핵심: 빨강만 200회, 파랑 50회처럼 치우치면 로봇이 "무조건 빨강"으로 편향돼요. 색마다 데이터 개수를 똑같이 맞추세요.

④ 학습 방식 : 통합 재학습이 핵심!

8번은 순차 학습의 함정에 걸리기 쉬워요. 여러분이 앞서 물어본 그 함정이에요.

🔴
8번은 순차학습 함정 주의! 색깔은 서로 다른 스킬이라, "빨강 100회 → 파랑 100회 → 초록 100회"처럼 순차로만 하면 나중 색을 배우다 앞 색을 까먹어요(파국적 망각). 7번(탑쌓기)과 정반대예요!
🧠
이해하기 쉽게!

영어 단어를 "월요일에 A그룹, 화요일에 B그룹"만 외우면 시험날 A를 까먹죠? 여러 그룹을 섞어서 외워야 다 기억나요. 색 분류도 여러 색을 섞어서 한 번에 학습해야 "빨강도 파랑도 초록도" 다 기억해요.

💡 7번과 왜 다른가? — 7번(2층→3층)은 포함관계라 순차 OK. 8번(빨강≠파랑≠초록)은 완전히 다른 색이라 통합 재학습이 안전해요.

⚠️ 순차로만 하면 앞 색을 까먹음 / ✅ 3색 데이터를 합쳐 재학습하면 모두 기억
학습 방식어떻게8번에서는?
통합 재학습
⭐추천		2색+초록 데이터를 합쳐서 처음부터 학습✅ 정답! 색끼리 안 까먹음. 균형 유지
순차 warm start빨강 → 파랑 → 초록 이어서⚠️ 위험. 앞 색을 까먹을 수 있음

💡
여러분 질문과 연결: "1단계 잘 됐고 2단계도 잘 되나?" → 8번은 색이 다른 스킬이라 2단계(초록) 후 1단계(빨강·파랑)를 꼭 재테스트! 떨어졌으면 통합 재학습으로. 7번과 정반대 케이스예요.

⑤ 색깔 선택 & 명령(single_task) 짝맞춤

색 분류는 색 대비와 명령 텍스트가 성공률을 좌우해요.

🎯
이해하기 쉽게!

비슷한 색은 사람도 헷갈리죠? 로봇은 더 심해요. 빨강·파랑·초록 원색을 쓰고, 통 색과 블록 색을 똑같이 맞춰요. 명령도 "빨강 블록을 빨강 통에"처럼 색↔통을 짝지어 정확히.

💡 실제로는 — 명령의 색 단어와 실제 색을 연결하는 게 "언어 grounding"이에요. 명령을 애매하게 쓰면(그냥 "정리해") 로봇이 뭘 어디 넣을지 몰라요.

🏷️ 명령(single_task) 짝맞춤 규칙

# 색마다 명령을 명확하게 — 색↔통 짝
# 빨강 데이터 녹화 시:
  single_task = "Put the red block in the red bin"
# 파랑 데이터 녹화 시:
  single_task = "Put the blue block in the blue bin"
# 초록 데이터 녹화 시:
  single_task = "Put the green block in the green bin"
⚠️
일관성이 생명: 명령 텍스트를 녹화·학습·추론에서 정확히 똑같이 쓰세요. "red bin"이라 녹화했으면 추론도 "red bin". 색 분류는 명령 이해가 핵심이라 텍스트 하나만 달라도 실패해요.
🎨
통도 색깔로: 통 자체를 블록 색과 같은 색으로 하면 로봇이 "빨강 블록 → 빨강 통"을 시각적으로도 연결하기 쉬워요. 통 위치는 좌우를 가끔 바꿔 수집해서 "위치가 아니라 색으로" 판단하게 하세요.

⑥ 실습 명령어 (녹화 → 통합학습 → 추론)

색마다 녹화하고, 합쳐서 통합 학습하는 게 핵심이에요.

1️⃣ 녹화 : 색마다 다른 single_task로

# 🔴 빨강 데이터 (색↔통 명령으로 100회)
lerobot-record --robot.type=so101_follower --robot.port=/dev/ttyACM0 \
  --dataset.repo_id=$HF_USER/sort_red \
  --dataset.single_task="Put the red block in the red bin" \
  --dataset.num_episodes=100 \
  --teleop.type=so101_leader --teleop.port=/dev/ttyACM1

# 🔵 파랑, 🟢 초록도 같은 방식으로 repo_id와 single_task만 바꿔 녹화
# → $HF_USER/sort_blue, $HF_USER/sort_green

2️⃣ 통합 학습 : 3색 데이터를 합쳐서 (핵심!)

# 3색 데이터를 합쳐서 처음부터 학습 (순차 아님!)
lerobot-train --policy.path=lerobot/smolvla_base \
  --dataset.repo_id=$HF_USER/sort_red,$HF_USER/sort_blue,$HF_USER/sort_green \
  --batch_size=64 --steps=25000 \
  --output_dir=outputs/train/color_sort --policy.device=cuda
💡
3색 데이터를 쉼표로 나열(또는 미리 하나로 병합)해서 합쳐 학습해요. 이러면 데이터셋 안에 색 3개 task가 담겨 멀티태스크 + 색 균형이 자동으로 돼요.

3️⃣ 추론 : 원하는 색 명령으로

# 빨강 블록을 빨강 통에 넣게 하려면 이 명령으로
lerobot-rollout --strategy.type=base \
  --policy.path=outputs/train/color_sort/checkpoint \
  --robot.type=so101_follower --robot.port=/dev/ttyACM0 \
  --task="Put the red block in the red bin" \
  --duration=60 --device=cuda
1
2색 녹화·학습 — 빨강·파랑 각 100회 → 합쳐서 학습 → 성공률 확인.
2
초록 추가·통합 재학습 — 초록 100회 녹화 → 3색 전체를 합쳐서 다시 학습.
3
색별 재테스트 — 빨강만·파랑만·초록만 각각 성공률 측정. 편향 없나 확인.
4
섞은 배치 테스트 — 통 위치를 좌우 바꾸거나 여러 블록 섞어 놓고 테스트.

⑦ 취업 포인트 & 종합 정리

색 분류는 어렵지만, 제대로 해내면 강력한 어필이 돼요.

🔴
기대치 관리: 색 분류는 원래 어려운 작업이에요(연구 성공률 0~10%). 처음부터 높은 성공률을 기대하기보다, "왜 어려운지 이해하고 성공률을 어떻게 올렸는지"를 보여주는 게 진짜 실력이에요.
💼 취업 포트폴리오 강점
"색 기반 자동 분류 + 언어 grounding + 통합 재학습"은 강력한 어필이에요:
① 재활용·물류 분류 자동화 직결 (산업 수요 큼) ② 어려운 작업을 설계로 개선(대비·통·균형) 증명 ③ 순차학습 함정을 알고 통합 재학습으로 해결(대부분 초보자가 모르는 부분). 통이 명확해 데모 영상도 이해하기 쉬워요!
🎯
8번의 핵심 3가지: ① 색 분류는 어렵다는 걸 인정하고 대비 ② 통합 재학습으로 색 안 까먹게 (7번과 정반대!) ③ 원색·통·명령 일관성으로 성공률 최대화.
🔗
다른 시나리오와 연결: 8번은 9번(색깔 공을 색깔 통에)과 결합할 수 있어요. "색깔 공을 색깔 통에" 하면 공의 구르기 문제까지 통이 해결해줘요. 색 분류 노하우가 그대로 이어져요.
💎 핵심 한 줄
색 분류는 SmolVLA가 가장 어려워하는 작업이지만, 그래서 제대로 해내면 차별점이 커요. 2색부터 시작해 통합 재학습으로 색을 안 까먹게 하고, 원색·통·명령 일관성으로 성공률을 올리는 게 8번의 정석입니다!
