🍩 무작위 링 정렬·재스택
정렬 → 페그에 끼우기

아무렇게나 놓인 링 3개를 크기순으로 정렬하고 막대(페그)에 큰 것부터 끼워 탑을 완성! 두 스킬을 이어 붙이는 롱호라이즌·스킬 체이닝의 대표 실습이에요.

스킬 체이닝 롱호라이즌 self-aligning 재시도 복구
① 무엇을 하나 ② 왜 링이 유리 ③ 2스킬 구조 ④ 체이닝·재시도 ⑤ 학습 방식 ⑥ 실습 명령어 ⑦ 취업 포인트

① 무엇을 하는 실습인가?

한 문장으로: 무작위로 놓인 링 3개를 크기순 정렬하고, 페그에 큰 것부터 끼워 탑 만들기.

🔴 난이도 : 상 (링이라 유리!) 🎯 2스킬 체이닝 (정렬+재스택) 📸 스킬 개별 → 연결
🍩
이해하기 쉽게!

도넛 3개가 책상에 아무렇게나 놓여 있어요. 로봇이 큰 것 → 중간 → 작은 것을 알아보고 정렬한 다음, 막대(페그)에 큰 것부터 끼워서 예쁜 탑을 만드는 거예요!

💡 실제로는 — 두 개의 다른 일이 이어져요: ①크기 판단하고 정렬 ②페그에 순서대로 끼우기. 이렇게 여러 작업을 연달아 하는 걸 "롱호라이즌(긴 작업)"이라고 해요.

🎬 전체 흐름: 무작위 링 3개 → 크기순 정렬(스킬A) → 페그에 큰 것부터 재스택(스킬B)

② 왜 링(도넛 모양)이 유리할까?

큐브 대신 링을 쓰면 파지도 정렬도 쉬워요. 링만의 장점이 있어요.

🎯
이해하기 쉽게!

도넛을 막대에 끼우는 놀이 있죠? 링은 가운데 구멍이 있어서 두 가지가 좋아요: ① 구멍이 있어 집기 쉽고 ② 막대(페그)에 끼우면 구멍이 저절로 중심을 잡아요. 큐브처럼 정중앙을 mm 단위로 안 맞춰도 돼요!

💡 실제로는 — 페그가 링 구멍의 중심을 자동으로 잡아주는 걸 "self-aligning(자동 정렬)"이라고 해요. 큐브 스택보다 오차에 관대해서 성공률이 더 잘 나와요.

🍩 큐브는 mm 단위 정밀이 필요하지만, 링은 페그가 중심을 자동으로 잡아줘요(self-aligning)
✅ 링의 장점

① 구멍이 있어 파지 안정 ② 페그가 자동 정렬 ③ 크기 차이로 순서 명확. 큐브 탑보다 성공률↑

⚠️ 그래도 어려운 점

2단계 연속이라 롱호라이즌. 정렬 실수가 재스택으로 이어지면 실패. 재시도 로직이 꼭 필요해요.

🎨
사진 속 링 활용: 색깔 링(주황·연두·파랑·분홍)을 그대로 쓰면 돼요. 크기마다 색이 다르면 로봇이 "지금 큰 링(분홍)"처럼 색+크기를 함께 보고 판단해 정렬이 쉬워져요. 3개면 크기 차이가 확실히 나는 링으로.

③ 두 개의 스킬로 나누기

한 번에 다 배우기 어려워요. 정렬(스킬A)과 재스택(스킬B)을 각각 배운 뒤 이어 붙여요.

🧩
이해하기 쉽게!

요리를 배울 때 재료 손질과 볶기를 따로 연습하고 합치죠? 로봇도 ①정렬과 ②재스택을 각각 잘하게 만든 다음, 순서대로 이어요. 한꺼번에 배우면 뭐가 문제인지 찾기 어려워요.

💡 실제로는 — 이걸 "스킬 분해(skill decomposition)"라고 해요. 긴 작업을 작은 스킬로 나눠 각각 마스터하고 연결하는 게 롱호라이즌의 정석이에요.

스킬 A
📏 크기순 정렬
200회

무작위 링 3개를 큰→중간→작은 순으로 한 줄 정렬. "Sort rings by size".

스킬 B
🍩 페그 재스택
200회

정렬된 링을 큰 것부터 페그에 끼우기. "Stack rings on the peg". 구멍이 정렬 도움.

🔍
왜 나누나? 스킬을 따로 배우면 어느 스킬이 약한지 바로 알 수 있어요. "정렬은 잘 되는데 재스택이 실패"처럼 문제를 콕 집어 개선할 수 있죠. 합쳐만 두면 디버깅이 어려워요.
💡
스킬 B는 스킬 A를 warm start: 정렬(A) 모델을 출발점으로 재스택(B)을 학습하면 "링 집기" 기본기가 공유돼 더 빨리 배워요. 단, 둘은 다른 스킬이라 학습 방식에 주의가 필요해요(⑤에서 설명).

④ 스킬 연결(체이닝)과 재시도 — 진짜 어려운 부분

두 스킬을 이어 붙일 때 "넘어가는 순간(hand-off)"이 가장 어려워요. 이걸 알면 성공률이 올라가요.

🔴
핵심 난제 (hand-off 문제): 정렬(A)이 끝난 상태를 재스택(B)이 본 적 없으면 실패해요. 예를 들어 A가 링을 조금 삐뚤게 정렬해 놓으면, B는 "삐뚤어진 링"을 학습 안 했으니 못 집어요. 스킬을 이을 때 이 연결 지점이 가장 위험해요.
🏃
이해하기 쉽게!

이어달리기에서 바통 넘기는 순간이 제일 실수 많죠? 앞 주자가 애매한 위치에 바통을 두면 뒤 주자가 못 잡아요. 로봇 스킬 연결도 똑같아요 — A가 끝낸 자리에서 B가 시작하는데, 그 자리가 B가 모르는 상태면 실패해요.

💡 해결법 — B를 학습할 때 "A가 만들 수 있는 다양한 상태"에서 시작하도록 데이터를 모아요. 그리고 재시도(안 되면 다시) 로직을 넣어요.

📉 각 스킬이 75%여도 연결하면 56%로 떨어져요. 그래서 "재시도/복구"가 필수예요

🔄 재시도(복구) 로직이 핵심

🔧
실전 핵심: "한 번에 완벽"을 기대하지 말고 "안 되면 다시"를 넣으세요. 링이 페그에 안 들어가면 → 다시 집어서 재시도. 실제 연구도 "복구 못할 때만 실패"로 쳐요. 재시도가 있으면 56% → 훨씬 높아져요.
🔗
체이닝 실행 방법: "정렬 끝나면 자동으로 재스택"은 기본 명령어엔 없어요. Python으로 작업 목록 만들어 순서대로 실행(정렬 완료 판단 → 재스택 명령)하는 체이닝 코드가 필요해요. 먼저 각 스킬을 따로 실행해 검증하고, 그다음 코드로 자동 연결하세요.

⑤ 학습 방식 : 정렬과 재스택은 다른 스킬

10번도 순차학습 주의가 필요해요. 정렬(A)과 재스택(B)은 완전히 다른 일이니까요.

🔴
10번은 순차학습 주의 케이스! 정렬(A)과 재스택(B)은 완전히 다른 스킬이에요. "A 200회 → B 200회" 순차로만 하면, B 학습 후 A(정렬)를 까먹을 수 있어요. 여러분이 앞서 물어본 함정의 대표 케이스예요. 8번(색 분류)과 비슷해요!
학습 방식어떻게10번에서는?
통합 재학습
⭐추천		정렬+재스택 데이터를 합쳐서 학습 (각 task 텍스트로 구분)✅ 안전! 두 스킬 다 기억. 명령으로 전환
순차 warm start정렬(A) → 재스택(B) 이어서⚠️ 주의. B 배우다 A를 까먹을 수 있음
따로 2개 모델정렬용·재스택용 모델 각각△ 각각 최고 성능 / ❌ 모델 2개 관리, 전환 복잡
💡
추천 조합: 정렬·재스택 데이터를 통합 재학습하면 한 모델이 두 스킬을 다 갖게 돼요(멀티태스크). 그다음 체이닝 코드로 "정렬 → 재스택" 순서를 실행하면 돼요. 능력은 통합 학습으로, 순서는 체이닝으로!
⚠️
꼭 확인: 재스택(B) 학습 후 정렬(A)도 다시 테스트하세요. A 성공률이 떨어졌으면 통합 재학습으로 전환. "다른 스킬이라 순차는 위험"하다는 걸 기억하세요.

🔀 7번·8번·10번 학습 방식 비교

시나리오1→2단계 관계학습 방식
7번 탑쌓기2층 ⊂ 3층 (포함)✅ 순차 warm start OK
8번 색 분류빨강 ≠ 파랑 (다른 스킬)⚠️ 통합 재학습
10번 링정렬 ≠ 재스택 (다른 스킬)⚠️ 통합 재학습
🔑
판별법: 2단계가 1단계를 포함/확장하면 순차 OK(7번), 완전히 다른 스킬이면 통합 재학습(8·10번). 10번은 "정렬과 재스택"이 다른 일이라 통합이 안전해요.

⑥ 실습 명령어 (녹화 → 통합학습 → 체이닝 추론)

스킬마다 녹화하고, 합쳐서 학습한 뒤, 체이닝으로 이어 실행해요.

1️⃣ 녹화 : 스킬마다 다른 single_task로

# 📏 스킬 A : 크기순 정렬 (200회)
lerobot-record --robot.type=so101_follower --robot.port=/dev/ttyACM0 \
  --dataset.repo_id=$HF_USER/ring_sort \
  --dataset.single_task="Sort the rings by size" \
  --dataset.num_episodes=200 \
  --teleop.type=so101_leader --teleop.port=/dev/ttyACM1

# 🍩 스킬 B : 페그 재스택 (200회) — repo_id·single_task만 변경
# --dataset.repo_id=$HF_USER/ring_restack
# --dataset.single_task="Stack the rings on the peg"
💡
재스택(B) 데이터는 정렬이 조금씩 다른 여러 상태에서 시작하도록 모으세요. 그래야 hand-off 문제(A가 만든 상태를 B가 못 보는 것)를 줄여요.

2️⃣ 통합 학습 : 두 스킬 데이터를 합쳐서

# 정렬·재스택 데이터를 합쳐서 학습 (통합 재학습)
lerobot-train --policy.path=lerobot/smolvla_base \
  --dataset.repo_id=$HF_USER/ring_sort,$HF_USER/ring_restack \
  --batch_size=64 --steps=25000 \
  --output_dir=outputs/train/ring_full --policy.device=cuda

3️⃣ 체이닝 추론 : 정렬 → 재스택 순서로

# 방법A) 따로 실행 : 정렬 먼저 → 끝나면 재스택
lerobot-rollout --policy.path=outputs/train/ring_full/checkpoint \
  --task="Sort the rings by size" --duration=40 ... # 정렬
lerobot-rollout --policy.path=outputs/train/ring_full/checkpoint \
  --task="Stack the rings on the peg" --duration=50 ... # 재스택

# 방법B) 체이닝 스크립트 (자동 연속 + 재시도)
tasks = ["Sort the rings by size", "Stack the rings on the peg"]
for task in tasks:  # 순서대로, 완료 판단 후 다음으로
  run_until_done(policy, robot, task, retry=2) # 재시도 2회
1
스킬 A 녹화·학습 — 정렬 200회 → 학습 → 정렬 정확도 확인.
2
스킬 B 녹화·통합 학습 — 재스택 200회 → A+B 합쳐서 학습.
3
각 스킬 따로 검증 — 정렬만·재스택만 각각 성공률 측정(방법A).
4
체이닝 + 재시도 — 두 스킬을 이어 실행. 안 되면 재시도(방법B).

💼 취업 포트폴리오 강점 (최강!)

① 인식(크기 판단) ② 계획(순서 정하기) ③ 조립(재스택) ④ 롱호라이즌 제어(체이닝·재시도)를 한 데모에! 실물 링이라 비전공 면접관도 이해하는 훌륭한 시연이에요.
