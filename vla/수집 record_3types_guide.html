🌐 글로벌 검증에서 조정한 3가지

업로드하신 명령어를 공식 가이드와 대조해 아래 3가지를 다듬었습니다.

🎞️

인코딩 설정을 카메라 대수에 맞췄습니다. 공식 스트리밍 가이드에 따르면 2대 640×480@30 조합은 스트리밍 인코딩이 캡처 루프와 경쟁할 수 있어, h264 코덱 + streaming_encoding=false(에피소드 사이 인코딩)를 권장합니다. 반면 3대 640×480@30은 기본 스트리밍이 잘 작동하고 오히려 스레드를 낮춰도 됩니다. 그래서 타입1·2는 비스트리밍, 타입3은 스트리밍으로 나눴습니다.

🔥

RealSense에 warmup_s: 15를 넣었습니다. RealSense는 켜자마자 안정적인 프레임을 못 내보내요. 15초 예열을 주면 초반 흔들린 프레임이 데이터에 섞이는 걸 막습니다. (업로드 2번엔 있었고 1번엔 없었는데, 둘 다 넣어 통일)

📼

OpenCV 카메라에 fourcc: "MJPG"를 통일했습니다. USB 웹캠 여러 대를 30fps로 동시에 돌리면 대역폭이 부족해 프레임이 떨어져요. MJPG 압축 포맷을 쓰면 대역폭을 아껴 안정적으로 30fps가 나옵니다.

1️⃣ 타입 1 — RealSense 2대

고품질 컬러(옵션으로 깊이까지). 정밀 작업이나 연구 트랙에 적합해요.

record_type1_realsense2.sh
lerobot-record \
  --robot.type=so101_follower \
  --robot.port=/dev/ttyACM1 \
  --robot.id=my_follower \
  --robot.cameras="{ top: {type: intelrealsense, serial_number_or_name: 116622071569,
                width: 640, height: 480, fps: 30, warmup_s: 15},
       side: {type: intelrealsense, serial_number_or_name: 047322070492,
                width: 640, height: 480, fps: 30, warmup_s: 15} }" \
  --teleop.type=so101_leader \
  --teleop.port=/dev/ttyACM0 \
  --teleop.id=my_leader \
  --display_data=true \
  --dataset.repo_id=data/pink_task_2rs \
  --dataset.push_to_hub=false \
  --dataset.num_episodes=30 \
  --dataset.single_task="pink block into the box of yellow" \
  --dataset.vcodec=h264 \
  --dataset.streaming_encoding=false \
  --dataset.encoder_threads=4
💡 이 타입의 특징

RealSense는 깊이(거리) 정보까지 얻을 수 있는 고급 카메라예요(필요하면 use_depth: true 추가). 두 대를 위·옆에 놓아 입체적으로 상황을 봅니다.

📸
전문가용 DSLR 두 대로 촬영하는 것과 같아요. 화질과 정보량은 최고지만, 그만큼 컴퓨터가 처리할 게 많아 인코딩을 조심스럽게(비스트리밍) 해야 해요.
⚠️2대라서 스트리밍 인코딩을 끄고 h264로 저장해요. 안 그러면 녹화 중 컴퓨터가 버벅여 프레임이 떨어질 수 있어요.

2️⃣ 타입 2 — 혼합 (웹캠 + RealSense)

손목엔 저렴한 USB 웹캠, 전체 뷰엔 RealSense. 비용과 품질의 현실적 절충안이에요.

record_type2_mixed.sh
lerobot-record \
  --robot.type=so101_follower \
  --robot.port=/dev/ttyACM1 \
  --robot.id=my_follower \
  --robot.cameras="{ arm: {type: opencv, index_or_path: 12,
                width: 640, height: 480, fps: 30, fourcc: \"MJPG\"},
       top: {type: intelrealsense, serial_number_or_name: \"138422072965\",
                width: 640, height: 480, fps: 30, warmup_s: 15} }" \
  --teleop.type=so101_leader \
  --teleop.port=/dev/ttyACM0 \
  --teleop.id=my_leader \
  --display_data=true \
  --dataset.repo_id=data/pink_task_mixed \
  --dataset.push_to_hub=false \
  --dataset.num_episodes=30 \
  --dataset.single_task="pink block into the box of yellow" \
  --dataset.vcodec=h264 \
  --dataset.streaming_encoding=false \
  --dataset.encoder_threads=4
💡 이 타입의 특징

돈을 아끼는 조합이에요. 손목처럼 가까이서 보는 카메라는 저렴한 웹캠(OpenCV)으로 충분하고, 전체 상황을 보는 상단만 고급 RealSense를 써요. 실무에서 가장 흔한 현실적 선택입니다.

🎥
중요한 전체 샷은 고급 카메라, 보조 샷은 저렴한 캠으로 찍는 것과 같아요. 예산은 아끼면서 핵심 화질은 지켜요.
📌웹캠엔 fourcc: "MJPG"(대역폭 절약), RealSense엔 warmup_s: 15(예열). 서로 다른 카메라라 각자 필요한 옵션을 챙겨줬어요.

3️⃣ 타입 3 — 웹캠 3대

일반 USB 웹캠 3대만으로 다각도 촬영. 가장 저렴하고 수업·입문에 표준이에요.

record_type3_opencv3.sh
lerobot-record \
  --robot.type=so101_follower \
  --robot.port=/dev/ttyACM1 \
  --robot.id=my_follower \
  --robot.cameras="{ top:   {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30, fourcc: \"MJPG\"},
       side:  {type: opencv, index_or_path: 2, width: 640, height: 480, fps: 30, fourcc: \"MJPG\"},
       wrist: {type: opencv, index_or_path: 4, width: 640, height: 480, fps: 30, fourcc: \"MJPG\"} }" \
  --teleop.type=so101_leader \
  --teleop.port=/dev/ttyACM0 \
  --teleop.id=my_leader \
  --display_data=true \
  --dataset.repo_id=data/pink_task_3cam \
  --dataset.push_to_hub=false \
  --dataset.num_episodes=30 \
  --dataset.single_task="pink block into the box of yellow" \
  --dataset.streaming_encoding=true \
  --dataset.encoder_threads=2
💡 이 타입의 특징

가장 저렴하고 구하기 쉬운 구성이에요. 일반 웹캠 3대를 위·옆·손목에 놓아 다각도로 봐요. 공식 가이드가 "3대 640×480@30은 기본 스트리밍이 잘 작동한다"고 명시해서, 여기선 스트리밍을 켠 채 씁니다.

📱
스마트폰 3대로 여러 각도에서 동시에 찍는 느낌이에요. 화질은 최고급은 아니지만, 여러 각도로 보니 로봇이 상황을 입체적으로 이해해요.
✅3대는 스트리밍이 안정적이라 streaming_encoding=true. 스레드는 2로 낮춰도 충분해요(가이드 권장).

⌨️ 녹화 중 키보드 조작 (3타입 공통)

시범을 보이는 도중 키보드로 흐름을 제어해요.

키동작언제 쓰나
→ 오른쪽이번 에피소드 저장하고 다음으로시범을 잘 마쳤을 때
← 왼쪽이번 에피소드 삭제하고 다시 녹화실수했을 때 (실패는 저장 금지!)
ESC중지 → 영상 인코딩 → 업로드모든 에피소드를 다 마쳤을 때
⚠️ 실행 전 체크: 카메라 시리얼/인덱스는 lerobot-find-cameras opencv (또는 realsense)로, 로봇 포트는 lerobot-find-port로 먼저 확인하세요. 재부팅하면 값이 바뀔 수 있어요.

📚 글로벌 검증: LeRobot 공식 cheat sheet·record API·카메라 문서에서 명령어 구조와 RealSense/OpenCV 설정을, 스트리밍 인코딩 가이드에서 "2대 640×480@30은 h264+비스트리밍 권장, 3대는 기본 스트리밍 양호, encoder_threads는 부하에 맞게 조정"을 확인했습니다. warmup_s·fourcc MJPG는 다수 실전 셋업 문서에서 교차 확인한 안정화 옵션입니다. 카메라 식별자는 재부팅 시 바뀔 수 있어 lerobot-find-cameras로 매번 확인이 권장됩니다.
