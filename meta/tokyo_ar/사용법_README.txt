========================================================
  리틀 도쿄 AR - 손으로 만지는 미니 도시 (사용법)
========================================================

■ 이게 뭔가요?
  Meta Quest 3 패스스루로 내 앞에 애니메이션 미니 도시가 나타납니다.
  - 맨손을 도시에 가까이 대면 → 불이 켜져 밝아집니다
  - 양손을 벌리면 → 도시가 커지고, 양손을 돌리면 → 도시가 회전합니다
  손 트래킹(컨트롤러 없이 맨손)으로 조작합니다.

■ 준비물
  - Meta Quest 3 (손 트래킹 켜두기)
  - PC (파이썬 + openssl - 대부분 있음)
  - PC와 Quest가 같은 WiFi

■ 실행
  1) PC에서 실행 스크립트 더블클릭
       윈도우 → 실행_윈도우.bat
       맥/리눅스 → 실행_맥리눅스.command
  2) 검은 창의 주소 확인: "Quest에서 보기: https://192.168.x.x:8443"

■ Quest 3에서
  1) 컨트롤러를 내려놓고 손 트래킹을 켭니다
       (설정 > 손과 컨트롤러 > 손 자동 전환 켜기)
  2) Quest 브라우저에서 위 주소 접속
  3) "연결이 비공개가 아님" → 고급 → 계속 진행
  4) "AR 시작(START AR)" 버튼 누르기
  5) 내 앞에 미니 도쿄가 나타납니다!

■ 조작법
  🖐 한 손을 도시에 가까이(35cm 이내) → 불이 켜짐
  ✋✋ 양손을 편 채로:
      - 두 손을 벌리면 → 도시가 커짐 / 모으면 작아짐
      - 두 손을 좌우로 돌리면 → 도시가 회전

■ 안 될 때 (계층별)
  1) 손이 안 보임 → Quest 손 트래킹이 켜졌나? 조명이 밝은가?
  2) AR 버튼 회색 → Quest 브라우저 최신인가?
  3) 주소 → https:// 인가? (http 아님)
  4) 인증서 → "계속 진행" 눌렀나?
  5) 도시 안 뜸 → 로딩이 좀 걸립니다(모델 4MB). 잠시 대기.

■ 값 조정 (index.html에서)
  - 만짐 거리: handleTouch()의 "d < 0.35" (숫자 키우면 더 멀리서도 켜짐)
  - 밝기: "targetIntensity = near ? 3.0" (숫자 키우면 더 밝게)
  - 도시 위치: group.position.set(0,0,-1.2) 마지막 값(거리)
  - 크기 제한: handleTwoHands()의 "0.15, 2.0"

■ PC 미리보기
  https://localhost:8443 → 마우스로 도시 확인 (AR/손조작은 Quest에서만)
