자동 경계 감지 사람 검수 서브태스크 분할 언어 주석 SmolVLA

자막 공장 파이프라인
자동 감지 → 검수 → 학습 데이터

로봇 영상에 "구간 자막"을 다는 전체 흐름을 공장 라인처럼 따라갑니다. 로봇 신호가 초안을 만들고, 사람이 검사하고, 두 갈래 포장 라인 중 하나로 출고됩니다.

🗺️ 전체 지도 — 자막 공장의 4개 작업대

🏭
이해하기 쉽게!

긴 로봇 영상(에피소드)은 자막 없는 영화 필름이에요. 이 공장은 필름에 "지금 뭐 하는 장면인지" 자막을 답니다. 작업대 1은 탐정 로봇이 초안 자막을 달고, 작업대 2는 선생님이 빨간펜으로 검사하고, 작업대 3에서 두 가지 포장 중 하나를 골라 출고합니다: 필름을 장면별로 싹둑 잘라 낱개 포장(🅐)하거나, 필름은 그대로 두고 자막 트랙만 끼워 포장(🅑)합니다.

🔧 작업대별로 무슨 일이 벌어지나

작업대🕵️
① 자동 경계 감지 — find_boundaries_multi.py
탐정 로봇: 영상을 보지 않고 "로봇 일기(관절 기록)"만 읽고 장면 전환점을 찾는다
단서 3개로 추리합니다: 그리퍼가 물건을 놓은 순간(release — 가장 확실한 단서), 손이 잠깐 느려진 순간(속도 최저점), 움직임 패턴이 확 바뀐 순간(변화점). 영상 분석(VLM)을 안 쓰니 시간이 정확하고 빠릅니다. 다만 가끔 틀리니 "초안"입니다.
입력: 데이터셋 (관절 기록) → 출력: boundaries.json (초안 자막)
작업대👩‍🏫
② 사람 검수·교정 — annotate_ui.html
선생님: 초안 자막을 실제 영상과 대조해 빨간펜으로 고친다
브라우저에서 열고 boundaries.json을 불러오면 검수 모드가 됩니다. 타임라인에 초안 구간이 색 블록으로 깔리고, 영상을 재생하며 "경계가 진짜 물건 놓는 순간과 맞나?"만 확인합니다. 틀린 곳만 I/O로 고치고, 에피소드 번호를 바꿔가며 순회합니다. 탐정이 ⚠️ 자신 없어 한 에피소드부터 보면 빠릅니다.
입력: boundaries.json + 영상 → 출력: boundaries_reviewed.json (확정 자막)
갈래✂️
🅐 장면별로 자르기 — split_by_subtask.py
긴 필름을 장면마다 싹둑 잘라, 낱개 필름 여러 개로 다시 포장
14초짜리 "탑 쌓기" 에피소드 1개가 → "Pick block1"(4.5초) + "Place block1"(4.5초) + "Pick block2"(5초)… 짧은 에피소드 여러 개로 바뀝니다. 각 조각의 task가 서브태스크 문장이 되므로, 모델이 "말 ↔ 짧은 행동"을 1:1로 배웁니다. 영상도 잘라 다시 인코딩하므로 시간이 좀 걸립니다.
입력: 원본 데이터셋 + 확정 자막 → 출력: 분할된 새 데이터셋 (에피소드 수 ↑)
갈래💬
🅑 자막 트랙만 추가 — apply_annotations.py
필름은 자르지 않고, DVD에 자막 트랙을 끼워 넣는다
에피소드는 그대로 두고, 프레임마다 "지금 몇 번 자막 구간인지" 번호(subtask_index)를 붙이고 자막 목록표(subtasks.parquet)를 새로 만듭니다. 영상 재인코딩이 없어 몇 초 만에 끝나고, 원본 구조가 보존됩니다. 확정 자막(--boundaries)을 바로 받을 수 있습니다.
입력: 원본 데이터셋 + 확정 자막 → 출력: 자막 열 추가된 복사본 (구조 유지)

🔀 🅐 vs 🅑 — 어느 포장 라인을 고를까?

✂️ 🅐 장면별로 자르기 (split)
비유필름을 잘라 낱개 포장
task 문장서브태스크로 교체
에피소드 수늘어남 (1개→N개)
처리 시간김 (영상 재인코딩)
쓰는 때긴 태스크를 짧게 배우기
언어 조향 강화 학습
💬 🅑 자막 트랙만 추가 (apply)
비유DVD에 자막 트랙 삽입
task 문장원본 유지 + 자막 열 추가
에피소드 수그대로
처리 시간몇 초 (parquet만)
쓰는 때원본 보존하며 분석·실험
v3.1 언어 스키마 방향
💡
수업 권장: SmolVLA 언어 조향 실습이 목적이면 🅐(split)이 정석입니다 — 학습되는 task 문장 자체가 서브태스크가 되어 효과가 직접적입니다. 🅑(apply)는 빠르고 안전해서 "자막 체계 검증·데이터 분석" 단계에 좋습니다. 확정 자막 하나로 둘 다 만들 수 있으니 시간이 되면 두 갈래를 비교 실험하는 것도 좋은 팀 과제입니다.

⌨️ 순서대로 치는 명령어

step1_자동감지.sh
# ① 탐정: 로봇 신호로 초안 자막 만들기
python find_boundaries_multi.py \
  --repo_id=$HF_USER/tower_long --n_subtasks=6 \
  --tasks "Pick block1" "Place block1" "Pick block2" "Stack block2" "Pick block3" "Stack block3" \
  --method=hybrid --out=boundaries.json --report
🖱️
② 선생님 검사 (명령어 없음 · 브라우저): annotate_ui.html 더블클릭 → 🎞️ 영상 선택 → 📂 boundaries.json 불러오기(검수 모드 자동 진입) → 에피소드 순회하며 확인·수정 → ⬇ boundaries.json (검수 완료본) 내보내기.
step3a_장면자르기.sh
# ③-🅐 확정 자막대로 에피소드 분할 (task = 서브태스크 문장)
python split_by_subtask.py \
  --src_repo_id=$HF_USER/tower_long \
  --dst_repo_id=$HF_USER/tower_long_split \
  --boundaries=boundaries_reviewed.json
step3b_자막트랙추가.sh
# ③-🅑 원본 유지 + subtask_index 열/자막표 추가 (몇 초면 끝)
python apply_annotations.py \
  --dataset_root=~/.cache/huggingface/lerobot/$HF_USER/tower_long \
  --boundaries=boundaries_reviewed.json \
  --output_dir=./exports/tower_long_annotated
step4_학습.sh
# ④ 분할본(🅐)으로 SmolVLA 파인튜닝 — task가 서브태스크 문장으로 들어감
lerobot-train --policy.type=smolvla --dataset.repo_id=$HF_USER/tower_long_split ...
⚠️
자주 하는 실수: ① 검수 없이 초안(boundaries.json)을 바로 ③에 넣기 — 탐정도 틀립니다, 꼭 선생님 검사를 거치세요. ② 라벨 어휘가 팀마다 제각각 — 추론 조향에 쓸 표현으로 통일표부터 만드세요. ③ 🅐는 영상 재인코딩이라 오래 걸림 — 수업 시간 배분에 반영하세요.

✅ 한 줄 요약

🎯

탐정(자동 감지)이 초안 자막을 달고 → 선생님(웹 UI)이 영상 보며 빨간펜 → 확정 자막으로 ✂️ 잘라서 배우거나(split) 💬 자막 트랙을 끼워(apply) 학습 데이터를 만든다. 자동은 빠르지만 틀릴 수 있고, 사람은 정확하지만 느리다 — 그래서 "자동 초안 + 사람 검수"가 가장 빠르고 정확한 조합입니다.
